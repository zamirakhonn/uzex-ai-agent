# Реестр сделок биржи — вымышленные данные / Birja bitimlari reyestri — o‘ylab topilgan ma’lumotlar

Все данные вымышленные: компании, ИНН, брокеры, контракты, сделки, цены и курс доллара придуманы. Формат повторяет
публичный реестр сделок товарно-сырьевой биржи. Совпадения с реальными организациями случайны.

Barcha ma’lumotlar o‘ylab topilgan: kompaniyalar, STIR, brokerlar, shartnomalar, bitimlar, narxlar va dollar kursi.
Format tovar-xomashyo birjasining ochiq bitimlar reyestrini takrorlaydi. Haqiqiy tashkilotlar bilan o‘xshashlik tasodifiy.

## Русский

### Файлы

| Файл | Что в нём |
|---|---|
| deals_2022.csv … deals_2026.csv | сделки по годам: 500 000 сделок со 3 января 2022 по 30 октября 2026 (2022: 84 299 · 2023: 93 985 · 2024: 106 647 · 2025: 115 763 · 2026: 99 306) |
| contracts.csv | карточки контрактов (6 616): товар и его атрибуты, единица и лот, валюта, базисная цена, сроки оплаты и поставки, продавец |
| participants.csv | компании — продавцы и покупатели (14 392) |
| brokers.csv | брокерские конторы (120) |
| usd_rates.csv | курс доллара на каждый календарный день, сум за 1 USD |

Все файлы — CSV в UTF-8, разделитель — запятая, первая строка — названия колонок. Значения с запятой внутри взяты
в кавычки. Даты — ДД.ММ.ГГГГ, время — по Ташкенту. Состояния сделок — на конец дня 30.10.2026.

### Сделки — deals_*.csv

| Колонка | Что значит |
|---|---|
| Номер сделки | сквозной номер по всем видам торгов; растёт по времени сделки; некоторые номера пропущены |
| Дата сделки, Время сделки | когда заключена сделка |
| Тип торгов | Английский аукцион — цена растёт от стартовой; Обратный аукцион — снижается от стартовой; Двусторонний аукцион |
| Количество | сколько лотов куплено |
| Сумма сделки | в валюте контракта (поле «Валюта» в contracts.csv); тысячи через пробел, дробная часть через точку |
| Стартовая цена | цена за одну единицу измерения, с которой начались торги, в валюте контракта |
| Номер контракта | карточка контракта в contracts.csv |
| Наименование товара | как в реестре: наименование и атрибуты одной строкой — «… Марка … Размер … Сорт … Тип … Класс …» |
| Лот, Единица измерения | сколько единиц измерения в одном лоте и какие это единицы |
| Регион | регион склада продавца |
| Тип контракта | Внутренний или Экспортный |
| Форма контракта | Спот, Форвард или Фьючерс |
| Состояние сделки | см. ниже |
| ИНН продавца, ИНН покупателя | компании из participants.csv |
| Брокер продавца, Брокер покупателя | коды брокерских контор из brokers.csv |
| Дата оплаты, Дата поставки | когда покупатель оплатил и когда товар поставлен; пусто, если этого ещё не было |
| Поставлено | сколько лотов фактически поставлено |

**Как считать.** Объём сделки в единицах измерения = Количество × Лот. Цена за единицу = Сумма сделки ÷ (Количество ×
Лот). Экспортные сделки — в долларах: сумма в сумах = Сумма сделки × курс на дату сделки из usd_rates.csv.

Карточку контракта заполняет продавец, поэтому один и тот же товар у разных продавцов может быть записан по-разному:
«1 сорт» и «1-сорта», с подписями полей и без, прописными буквами.

| Состояние сделки | Что значит |
|---|---|
| Новый | сделка заключена в последний день выгрузки, 30.10.2026 |
| Не подписан | договор ещё не подписан сторонами |
| Заключен | форвард или фьючерс подписан, срок оплаты ещё не истёк |
| Ждёт оплату | спот подписан, срок оплаты ещё не истёк |
| Оплачен | оплачен, товар ещё не поставлен |
| Исполнен | оплачен и поставлен полностью |
| Исполнен(Частично) | оплачен, поставлена часть — сколько лотов, видно в «Поставлено» |
| Аннулирован(Не оплачен) | не оплачен в срок и аннулирован — сделка не состоялась |

### Карточки контрактов — contracts.csv

| Колонка | Что значит |
|---|---|
| Номер контракта | на него ссылаются сделки |
| Наименование продукта; Марка, Размер, Сорт, Тип, Класс товара | как заполнил продавец; если поля атрибутов пустые, всё записано в наименовании |
| Код ТН ВЭД, Группа товара, Категория товара, Отрасль промышленности | классификация товара |
| Единица измерения, Лот | те же, что в сделках по этому контракту |
| Валюта | Узбекский сум или Доллар США — в этой валюте суммы и цены сделок по контракту |
| Базисная цена | цена за единицу измерения на дату регистрации контракта |
| Сумма залога | залог в процентах от суммы сделки |
| Базис поставки, Упаковка | условия поставки |
| Регион, Адрес склада | где хранится товар |
| Тип торгов, Тип контракта, Форма контракта | те же, что в сделках по этому контракту |
| Срок оплаты | календарных дней от даты сделки, за которые покупатель должен оплатить |
| Срок поставки | календарных дней от даты оплаты, за которые продавец должен поставить товар |
| ИНН продавца | компания из participants.csv |
| Дата регистрации, Действует до | в этот период по контракту заключаются сделки |

### Участники, брокеры, курс

participants.csv — ИНН (9 цифр), наименование, регион, вид деятельности, роль (Продавец или Покупатель), плательщик
НДС. brokers.csv — код брокера, наименование, ИНН, регион. usd_rates.csv — дата и курс, сум за 1 USD.

## O‘zbekcha

**Fayllar.** deals_2022.csv … deals_2026.csv — yillar bo‘yicha bitimlar (500 000 ta, 2022-yil 3-yanvardan
2026-yil 30-oktabrgacha). contracts.csv — shartnoma kartochkalari. participants.csv — sotuvchi va xaridor
kompaniyalar. brokers.csv — broker idoralari. usd_rates.csv — har bir kun uchun dollar kursi (1 USD uchun so‘m).
Hammasi UTF-8 kodlashdagi CSV, ajratuvchi — vergul. Sanalar — KK.OO.YYYY, vaqt — Toshkent vaqti. Bitim holatlari —
2026-yil 30-oktabr kuni oxiridagi holat.

**Qanday hisoblanadi.** Bitim hajmi (o‘lchov birligida) = Количество × Лот. Birlik narxi = Сумма сделки ÷ (Количество ×
Лот). Summa va boshlang‘ich narx — shartnoma valyutasida (contracts.csv dagi «Валюта»): so‘m yoki AQSh dollari;
eksport bitimining so‘mdagi summasi = summa × bitim sanasidagi kurs (usd_rates.csv).

**Kartochkani sotuvchi to‘ldiradi**, shuning uchun bir xil tovar turli sotuvchilarda turlicha yozilishi mumkin.

**Bitim holatlari:** Новый — oxirgi kun (30.10.2026) tuzilgan; Не подписан — hali imzolanmagan; Заключен — forvard yoki
fyuchers imzolangan, to‘lov muddati o‘tmagan; Ждёт оплату — spot imzolangan, to‘lov muddati o‘tmagan; Оплачен —
to‘langan, hali yetkazilmagan; Исполнен — to‘langan va to‘liq yetkazilgan; Исполнен(Частично) — qisman yetkazilgan
(«Поставлено» ustuniga qarang); Аннулирован(Не оплачен) — muddatida to‘lanmagan va bekor qilingan, bitim amalga oshmagan.

**Muddatlar.** «Срок оплаты» — bitim sanasidan boshlab kalendar kunlari; «Срок поставки» — to‘lov sanasidan boshlab
kalendar kunlari.
